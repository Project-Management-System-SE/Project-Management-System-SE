Authentication

Pass your authentication token via HTTP Authorization header:

Authorization: Bearer <your_api_token>

Standard browser session authentication is supported for read requests. Unsafe write requests on the API require a Bearer token.

Rate Limiting & Throttling

Throttling is applied per authenticated user (or per IP for anonymous callers):

  • Read requests (GET/HEAD): 60 requests per 60-second window
  • Write requests (POST/PATCH/PUT/DELETE): 20 requests per 60-second window

When the limit is exceeded, the server returns 429 Too Many Requests with a Retry-After header indicating seconds to wait.

Pagination & Error Format

Pagination: List endpoints support ?page=1&page_size=25 (page size up to 100). The response envelope includes count, page, page_size, next_page, and previous_page.

Standard Error Format: All error responses follow a consistent JSON envelope:

{
  "status": "error",
  "message": "Validation message or error summary",
  "errors": { "field_name": ["Specific error description"] }
}

Endpoints Overview

  • GET /api/v1/projects/ List accessible projects (filterable, paginated)
  • GET /api/v1/projects/{project_id}/ Retrieve project details
  • GET /api/v1/projects/{project_id}/tasks/ List project tasks (supports status, sprint, priority, date filters)
  • POST /api/v1/projects/{project_id}/tasks/ Create task (validated, requires membership)
  • GET PATCH DELETE /api/v1/tasks/{task_id}/ Retrieve, update fields, or delete task
  • POST /api/v1/tasks/{task_id}/status/ Update task status (enforces Review before Done)
  • GET POST /api/v1/projects/{project_id}/members/ List and add project members
  • PATCH DELETE /api/v1/projects/{project_id}/members/{membership_id}/ Update role or remove member
  • GET PUT /api/v1/projects/{project_id}/workflow/ Get or configure custom workflow states and transitions
  • GET POST /api/v1/projects/{project_id}/sprints/ List and create project sprints
  • GET POST /api/v1/projects/{project_id}/milestones/ List and create project milestones
  • GET POST /api/v1/projects/{project_id}/tasks/{task_id}/comments/ List and add task comments
  • GET /api/v1/projects/{project_id}/reports/ Project progress, velocity, and workload metrics
