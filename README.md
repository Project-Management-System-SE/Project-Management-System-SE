# Project Management System

A Software Engineering project focused on designing and developing a Project Management System to efficiently manage projects, tasks, workflows, sprints, and team collaboration.

## Team 11

### Project Overview

The Project Management System provides a centralized platform for managing project activities. It helps teams create and manage projects, assign tasks, track progress using Kanban boards, estimate work, manage sprints, and monitor project performance.

## Key Areas

- User authentication and role-based access
- Project and team management
- Task and issue management
- Kanban board and workflow management
- Task estimation and effort tracking
- Sprint and milestone management
- Project dashboards and visibility
- Notifications and team collaboration
- Search and filtering
- Reports and activity logs
